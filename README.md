# Bolinhas para Windows

Instaladores do **Bolinhas**, app de voz e transmissão de tela para grupos de amigos. Este repositório guarda só os instaladores. O app instalado se atualiza sozinho a partir das versões publicadas aqui.

## Baixar

1. Abra a [última versão](https://github.com/TomD4vs/bolinhas-releases/releases/latest).
2. Em **Assets**, baixe o arquivo `Bolinhas-Setup-<versão>.exe`.
3. Abra o arquivo baixado. O Bolinhas instala só para o seu usuário, sem pedir senha de administrador, e cria um atalho na área de trabalho.

> **"O Windows protegeu o computador"**
>
> O instalador não tem assinatura de código, que é paga. Na primeira instalação, o Windows mostra esse aviso. Clique em **Mais informações** e depois em **Executar assim mesmo**. As atualizações seguintes instalam sozinhas, sem o aviso.

## Requisitos

- Windows 10 ou 11, 64 bits.
- Microfone. Para transmitir a tela em alta qualidade, placa de vídeo com encoder H.264 (NVIDIA, AMD ou Intel).

## Sem instalar

Dá para entrar nas salas pelo navegador, em https://bolinhas.bolinhas.workers.dev, no Chrome ou no Edge.

## Atualizações

O app confere se há versão nova ao abrir e a cada 6 horas. A versão nova é baixada em segundo plano e instalada quando você fecha o app. Se uma sala pedir uma versão mais nova, o botão **Atualizar agora** instala na hora.
